# Docs

Shared standards for every OAN Frappe app. Each file covers one topic and stands alone.

| File                            | Covers                                                       |
| ------------------------------- | ------------------------------------------------------------ |
| `DEVELOPMENT_BEST_PRACTICES.md` | How to write and maintain the code.                          |
| `API_CONVENTIONS.md`            | Public URLs, versioning, deprecation, endpoint checklist.    |
| `DATA_MODELLING.md`             | When to use a field, a DocType, a child table or a snapshot. |
| `RUNTIME_ARCHITECTURE.md`       | Process layout: workers, scheduler, Redis, file storage.     |
| `VERIFICATION_PIPELINE.md`      | Pre-commit, pre-push and CI gates.                           |
| `GIT_WORKFLOW.md`               | Branches, commits, merge hygiene, pull requests.             |
| `STANDARDS_DEVIATIONS.md`       | Where the current apps do not follow these standards yet.    |

`oan_auth_service`'s own reference: `API_DOCUMENTATION.md`, `IAM_DELEGATED_LOGIN_PLAN.md`.
